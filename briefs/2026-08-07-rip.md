### Deliverables

1. **Benchmarking Results:**
   - Evaluate generation throughput for 25 quantized open-source LLMs across Raspberry Pi 4, Raspberry Pi 5, and Orange Pi 5 Pro.
   - Compare Ollama and Llamafile performance under varying CPU configurations.
   - Measure memory usage and power consumption.

2. **Key Findings:**
   - SBCs can reliably support models up to 1.5B parameters.
   - Llamafile achieves up to 4x higher throughput than Ollama.
   - Llamafile consumes 30-40% less power than Ollama on average.

3. **Recommendations:**
   - For generative tasks, recommend using Llamafile with Raspberry Pi 5 and Orange Pi 5 Pro for models up to 1.5B parameters.
   - For lower resource requirements (e.g., non-generative or high-latency tasks), Ollama remains viable on all three SBCs.

4. **Limitations:**
   - Performance varies significantly with CPU configurations.
   - Memory and power consumption need further optimization for higher-end models like 7B+.
   - Power efficiency improves with Llamafile, but not consistently across different CPUs and models.

5. **Future Work:**
   - Investigate the impact of custom hardware optimizations on inference performance.
   - Explore more model quantization techniques to improve resource utilization.
   - Develop a comprehensive toolchain for deploying and managing LLMs on SBCs.
