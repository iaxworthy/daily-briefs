# Daily Brief — 2026-08-02

## Edge AI / On-Device LLM
**NVIDIA TensorRT-Edge-LLM (v0.9.1)** is the story here — a purpose-built C++ inference runtime for LLMs/VLMs on Jetson-class hardware, positioned explicitly for "Physical AI" (robotics/embodied agents), not general edge chat. 485 stars, created Oct 2025, active dev (59 open issues). Matters because it signals NVIDIA is building a lightweight alternative to full TensorRT-LLM specifically for edge/robotics deployment rather than datacenter inference — worth tracking if you're deploying on Jetson.

Pairs with NVIDIA's own **Dec 2025 Jetson blog post** walking through deploying open LLMs/VLMs locally and the shift toward foundation-model-driven robotics (Isaac GR00T N1) over hand-coded control — same push, different layer of the stack.

Google's **on-device SLM update (May 2025)** is older news resurfacing: Gemma 3n as the first multimodal on-device Gemma (text/image/video/audio) plus new RAG and function-calling libraries for Android/iOS/Web. Still the most complete "build an on-device agent" toolkit in this space if you're not on NVIDIA hardware.

Noise: the IEEE and MDPI survey papers are generic literature reviews, nothing actionable. picoLLM's accuracy claims (99.9% retained at 3-bit) are vendor marketing — no independent benchmark attached, treat skeptically.

## Meshtastic / LoRa Mesh
No major news — this beat is steady-state. `meshtastic/firmware` (8k stars) remains the active core project with heavy contributor traffic; docs/website repo is separate and stable. Nothing changed enough to flag as new signal today; useful mainly as reference material if you're setting up hardware.

## Raspberry Pi + Local Inference
Real signal: an **arXiv benchmark (Nov 2025)** testing 25 quantized LLMs across Pi 4, Pi 5, and Orange Pi 5 Pro on Ollama vs. Llamafile — finding SBCs reliably handle models up to ~1.5B params, with Llamafile hitting 4x the throughput and 30–40% less power draw than Ollama. If you're choosing a runtime for Pi-based inference, that's an actionable data point, not just vendor claims.

Everything else in this beat is low-credibility hobbyist noise: **potato-os** and **pi-llm** are single-contributor repos with 0–6 stars, unreleased or barely-released, making unverified performance/compression claims ("true 1-bit quantization," specific accuracy retention) with no benchmarks attached. Worth a bookmark if you like tinkering, not worth treating as validated technique. The Adafruit/Arm/XDA pieces are solid intro-level walkthroughs but not new — background reading, not news.

**Bottom line:** the actual move today is NVIDIA doubling down on edge/robotics inference infra (TensorRT-Edge-LLM + Jetson tooling), and one useful hard number — Llamafile beats Ollama 4x on Pi throughput. Rest is steady-state or marketing chaff.
