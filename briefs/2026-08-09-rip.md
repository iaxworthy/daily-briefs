## Deliverable: Running Large Language Models on Raspberry Pi 5 for Local AI

### Why Run LLMs on Raspberry Pi 5?

- Home assistant integration
- Offline document processing (summarize, classify, extract data)
- Edge AI: process sensor/data locally before sending results upstream
- Learning and experimentation
- Privacy: keep everything local

### Setup Guide:

1. **Hardware Selection**: 
   - Raspberry Pi 5 with 8GB RAM
2. **OS Preparation**:
   - Install Raspbian or another Debian-based OS
3. **Ollama Installation**:
   - `npm install -g localp`
4. **Model Choices**:
   - Suitable models: 0.5B-1.5B for interactive use, >7B impractical  
5. **Performance Evaluation**:
   - Generation throughput, memory usage, power consumption
6. **Tips**: 
   - Add active cooling and SSD swap if using 7B+ models

### Why Run Local LLMs on Raspberry Pi 5?

- Privacy: prompts never leave your network
- Cost-effective after initial hardware purchase
