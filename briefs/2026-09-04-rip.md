### Deliverable: Performance Benchmark Report for Local LLM Inference on Raspberry Pi

**Objective:** To evaluate the performance of 25 quantized open-source Large Language Models (LLMs) running locally on three popular single-board computers (SBCs): Raspberry Pi 4, Raspberry Pi 5, and Orange Pi 5 Pro. 

**Methodology:**
- Tested models were quantized to reduce inference time.
- Two inference runtimes used: Ollama and Llamafile.
- Benchmarked generation throughput, memory usage, and power consumption under varying CPU configurations.
- Used multiple prompt types to simulate realistic workloads.

**Results:**
- SBCs can reliably support models up to 1.5B parameters.
- Llamafile achieved higher generation throughput compared to Ollama across all tested scenarios.
- Memory usage was lower for Llamafile, with a slight increase in power consumption on Pi 4 and Pi 5.

**Recommendations:**
- For Raspberry Pi 4 (8 GB), use Llamafile runtime for optimal performance.
- Raspberry Pi 5 can run up to 1.5B models efficiently using either Ollama or Llamafile, with slight preference for Llamafile based on current results.
- Orange Pi Pro may struggle with larger models but still viable for smaller ones.

**Conclusion:**
SBCs are suitable platforms for localized LLM inference. Raspberry Pi 4 and Pi 5 offer good performance even with slightly higher power consumption, making them ideal for edge AI applications without cloud services.
