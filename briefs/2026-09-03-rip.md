### Running DeepSeek R1 Locally on a Raspberry Pi

#### Deliverable

To run DeepSeek R1 locally on a Raspberry Pi 5:

**Hardware Requirements:**
- Raspberry Pi 5 (8GB or 16GB RAM recommended)
- MicroSD card with Raspberry Pi OS installed
- Stable power supply and internet connection

**Software Requirements:**
- Basic familiarity with Raspberry Pi OS and terminal commands
- Docker (optional for containerized applications)

#### Steps:

1. **Prepare the Raspberry Pi:**
   - Install Raspberry Pi OS on a microSD card.
   - Ensure stable power and internet connection.

2. **Install Docker (Optional):**
   - Connect to the Raspberry Pi via SSH or by plugging in the microSD card.
   - Update package list and install Docker:
     ```bash
     sudo apt update
     sudo apt install docker.io
     ```

3. **Clone DeepSeek R1 Repository:**
   - Clone the DeepSeek R1 repository from GitHub or your preferred source.
   - Ensure you have all dependencies installed (e.g., Python, CUDA).

4. **Run DeepSeek R1 Model:**
   - Navigate to the cloned repository directory.
   - Run the model using Docker for containerized applications:
     ```bash
     docker run --gpus all -it deepseek_r1 /path/to/your/model/file
     ```

5. **Evaluate Performance:**
   - Measure generation throughput, memory usage, and power consumption under varying CPU configurations.
   - Test different prompt types to simulate realistic workloads.

#### Notes:
- Raspberry Pi 5 is a capable platform for running DeepSeek R1 models but may require optimizations for best performance.
- Docker can provide isolation and ease deployment of complex model environments.
- Experiment with different prompts to understand the impact on generation quality and speed.
