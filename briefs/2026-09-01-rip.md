# Deliverable: Running DeepSeek R1 Locally on a Raspberry Pi

## Prerequisites:

1. **Hardware:**
   - Raspberry Pi 5 (8GB or 16GB RAM recommended)
   - MicroSD card with Raspberry Pi OS installed (64-bit)
   - Stable power supply and internet connection.

2. **Software:**
   - Basic familiarity with Raspberry Pi OS and terminal commands.
   - Docker (optional, for containerized applications).

## Steps:

### Step 1: Set Up Your Environment

1. Install Raspberry Pi OS on your MicroSD card if not already done.
2. Insert the MicroSD card into your Raspberry Pi 5.
3. Connect to your Raspberry Pi via SSH or a local network connection.

### Step 2: Update and Upgrade System

```sh
sudo apt update && sudo apt upgrade -y
```

### Step 3: Install Docker (Optional)

If you plan on using Docker for containerized applications, install it:

```sh
sudo apt-get install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker
```

### Step 4: Clone the Model Repository

```sh
git clone https://github.com/your-repo/deepseek-r1.git
cd deepseek-r1
```

### Step 5: Build and Run DeepSeek R1 Docker Container

```sh
# Use your preferred image name if different from 'deepseek'
docker build -t deepseek .
docker run --name my-deepseek-container -p 8080:8000 -d deepseek
```

### Step 6: Access the Model via UI

Open a web browser and navigate to `http://<your-Raspberry-Pi-ip>:8080`. You should see the DeepSeek R1 model interface.

## Evaluation:

- **Generation Throughput**: Measure how many text generations per second your Raspberry Pi can handle.
- **Memory Usage**: Monitor system memory usage during inference.
- **Power Consumption**: Note any changes in power draw while running the model.

By following these steps, you can successfully deploy and run DeepSeek R1 on a Raspberry Pi 5 for local AI processing.
