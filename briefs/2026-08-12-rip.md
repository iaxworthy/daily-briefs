### Deliverable: Deliver Mesh Protocol Overview for LoRa Network

#### Layer 0: LoRa Radio
1. **Data Encoding**: All data packets are encoded into LoRa symbols with a fixed preamble at the start.
2. **Preamble Functionality**:
   - Synchronizes clocks among nodes.
   - Enables initial synchronization before packet transmission.

#### Layer 1: Mesh Protocol Management
1. **Broadcasts and Direct Messages**:
   - Uses a hybrid approach for broadcasts and direct messages, leveraging the mesh routing algorithm.
   - Enhanced version of Flood Routing with listening to detect concurrent rebroadcasts.
2. **Routing Protocol**: 
   - Managed Flood Routing implemented to optimize efficiency and reduce network congestion.

#### Layer 2: Sub-packets
1. **Message Structure**:
   - Mesh packets contain sub-packets that are serialized using Protocol Buffers for efficient transmission across vendors.
   
#### Layer 3: Application Layer
1. **Application Packets**:
   - Custom application layer protocols built on top of mesh and sub-packet layers to support specific functionalities.

This layered approach ensures robust, scalable, and efficient communication in a LoRa-based wireless mesh network.
